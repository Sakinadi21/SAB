# SABAS – সাবাশ
### প্রস্তুতি হোক সবার গাইডলাইনে

**SABAS** is a Bengali educational platform designed to help students prepare for university admission through structured learning resources, experienced mentors, and course-based guidance.

The platform provides students with an overview of available courses, mentor profiles, and learning opportunities in one place.

## 🌟 Project Overview

SABAS aims to make quality educational guidance more accessible to students. Its interface is designed primarily for Bengali-speaking learners, with a focus on university admission preparation.

## ✨ Features

- **Mentor Profiles:** Introduces experienced mentors along with their academic institutions and backgrounds.
- **Course Showcase:** Displays featured admission preparation courses.
- **Course Details:** Provides course information through an interactive modal.
- **Enrollment Access:** Directs students to the relevant course enrollment page.
- **Learning Resources:** Highlights tutorials, model tests, practice sheets, quizzes, and PDF solution sheets.
- **Responsive Design:** Uses CSS styling to support different screen sizes.
- **Bengali Interface:** Designed to make educational information accessible to Bengali-speaking students.
